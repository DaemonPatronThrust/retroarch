## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **400+ Cores** | Emulate everything from Atari 2600 to PlayStation 3 and beyond |
| **Shaders** | CRT, LCD, and artistic shaders transform the look of any emulated game |
| **Netplay** | Online multiplayer for emulated games across many cores |
| **Universal Save States** | Consistent save/load controls that work the same across every core |
